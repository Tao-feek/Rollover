Bet Rollover Planner - offline app (PWA)

1. Upload ALL files in this folder to any HTTPS host (e.g. drag the unzipped folder onto app.netlify.com/drop, or use GitHub Pages / Vercel).
2. Open the hosted address once on your phone while online.
3. Add to Home Screen (iPhone: Share > Add to Home Screen. Android: menu > Install app).
After that it opens and works with no internet. Progress is saved on the device.
